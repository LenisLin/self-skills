# Precise Modification Planning

Produce a concise, executable modification plan grounded in the relevant existing content.

For each planned change, state the file path, exact edit location, current relevant content, and intended replacement, addition, merge, move, or removal.

Preserve useful existing content, consolidate repetition, and resolve conflicts instead of adding parallel overlapping text.

For code, specify script headers, functions, key variables, and comments needed for non-obvious logic.

When constraints, procedures, or repeated operations are fixed, express them as a stepwise workflow, checklist, or reusable template.

Use short, precise, human-readable language. Prefer positive constraints. Inspect more files only when context is insufficient.
